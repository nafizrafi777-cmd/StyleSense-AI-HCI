# StyleSense-AI-HCI

## Project Overview

StyleSense is an AI-based conversational fashion shopping assistant designed to provide
catalog-grounded product recommendations through natural-language interaction.

## Project Goals

- Provide natural-language shopping assistance
- Generate catalog-grounded recommendations
- Avoid inventing products or product information
- Support conversational interaction
- Apply AI and HCI principles to improve the shopping experience
